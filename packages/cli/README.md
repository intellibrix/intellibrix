# @intellibrix/cli

The intellibrix CLI: `intellibrix init` scaffolds a project and `intellibrix mcp serve <entry>` exposes a Brick over MCP.

Part of [intellibrix](https://github.com/intellibrix/intellibrix), a model-agnostic TypeScript framework for building agents and AI-powered software components. Requires Node 22+.

## Install

```sh
npm install @intellibrix/cli intellibrix
```

## Usage

```sh
npx @intellibrix/cli init
npx @intellibrix/cli mcp serve ./src/brick.ts
```
