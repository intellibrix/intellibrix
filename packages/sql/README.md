# @intellibrix/sql

SQL-backed key-value store (Sequelize) and Postgres + pgvector vector store for intellibrix.

Part of [intellibrix](https://github.com/intellibrix/intellibrix), a model-agnostic TypeScript framework for building agents and AI-powered software components. Requires Node 22+.

## Install

```sh
npm install @intellibrix/sql intellibrix sequelize
```

## Usage

Exports `SQLInterface` (SQL-backed database and key-value store over Postgres, MariaDB or SQLite) and `PgVectorStore` (HNSW). Install the driver peer for your database.
