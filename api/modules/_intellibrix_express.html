    @intellibrix/express

    Express brick for intellibrix with /ask and SSE streaming routes.

    Part of intellibrix, a model-agnostic TypeScript framework for building agents and AI-powered software components. Requires Node 22+.

    Install

    npm install @intellibrix/express intellibrix express

    Usage

    Exposes askRoute and askStreamRoute, which serve an Intelligence or Brick over HTTP (JSON and server-sent events).
