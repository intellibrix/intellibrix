    @intellibrix/i18n

    I18n brick for intellibrix, powered by i18next.

    Part of intellibrix, a model-agnostic TypeScript framework for building agents and AI-powered software components. Requires Node 22+.

    Install

    npm install @intellibrix/i18n intellibrix i18next

    Usage

    Each instance uses i18next.createInstance(), so several bricks never share global state.
