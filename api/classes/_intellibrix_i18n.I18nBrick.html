    Class I18nBrick

    Class representing an I18n (Internationalization) Brick. It extends from the Brick class.

    Example

    const brick = new I18nBrick({ resources: { es: { translation: { 'Hello': 'Hola' } } } })
    brick.language = 'es'
    console.log(brick.t('Hello')) // 'Hola'
