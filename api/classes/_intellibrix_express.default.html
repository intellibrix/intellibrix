    Class default

    Class representing a brick that sets up an Express server. It extends from the intellibrix!Brick class.

    Access all of Express's functionality through the ExpressBrick.express property.

    Example

    const brick = new ExpressBrick({
      port: 3000,
      routes: [
        {
          path: '/',
          method: 'get',
          handler: (req, res) => {
            res.status(200).send('Hello World')
          }
        },
        {
          path: '/echo',
          method: 'post',
          handler: (req, res) => {
            res.status(200).json(req.body)
          }
        }
      ]
    })
