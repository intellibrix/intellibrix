A chat that remembers

Each threadId is its own conversation. @intellibrix/memory-sqlite uses Node’s built-in node:sqlite, so there is nothing native to install. For a shared database, @intellibrix/sql provides a SQL-backed store. To implement your own, run the conversationMemoryContract suite from intellibrix/testing.
